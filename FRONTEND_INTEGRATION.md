# Frontend Integration Guide

How to connect your Chuckleclips website to the backend feed API.

## Configuration

Set your backend URL (Zeabur deployed URL):

```javascript
const BACKEND_URL = 'https://your-zeabur-url.com';
// Example: 'https://chuckleclips-backend-abc123.zeabur.app'
```

## Fetching the Feed

```javascript
async function loadLatestClips() {
  try {
    const response = await fetch(`${BACKEND_URL}/api/feed`);
    const { success, data, lastUpdated } = await response.json();
    
    if (!success) {
      console.error('Failed to load feed');
      return [];
    }
    
    return data; // Array of video objects
  } catch (error) {
    console.error('Feed fetch error:', error);
    return [];
  }
}
```

## Video Object Structure

Each video in the feed has:

```javascript
{
  id: "youtube_abc123",              // Unique ID
  title: "Auntie vs Gen Z",           // Video title
  description: "...",                 // Full description/caption
  thumbnail: "https://...",           // Thumbnail image URL
  publishedAt: "2024-01-15T09:00Z",   // ISO timestamp
  platform: "YouTube",                // Primary platform
  platforms: ["YouTube", "Instagram", "TikTok"], // All platforms it's on
  url: "https://youtube.com/watch?v=...", // Direct link to watch
  originalId: "abc123"                // Platform-specific ID
}
```

## HTML Card Template

Replace your hardcoded video cards with dynamically generated ones:

```html
<div id="videoGrid" class="video-grid">
  <!-- Generated by JavaScript -->
</div>

<script>
const BACKEND_URL = 'https://your-zeabur-url.com';

async function loadLatestClips() {
  try {
    const response = await fetch(`${BACKEND_URL}/api/feed`);
    const { success, data } = await response.json();
    
    if (!success) {
      console.error('Failed to load feed');
      return [];
    }
    
    return data;
  } catch (error) {
    console.error('Feed fetch error:', error);
    return [];
  }
}

async function renderLatestClips() {
  const clips = await loadLatestClips();
  const grid = document.getElementById('videoGrid');
  
  grid.innerHTML = clips.map(clip => {
    return `
      <a href="${clip.url}" target="_blank" rel="noopener" class="video-card">
        <div class="video-thumbnail" style="background-image: url('${clip.thumbnail}'); background-size: cover;">
          <span class="video-platform">${clip.platform}</span>
        </div>
        <div class="video-info">
          <h3 class="video-title">${escapeHtml(clip.title)}</h3>
          <div class="video-meta">
            <span>${clip.platforms.join(' • ')}</span>
            <span class="watch-cta">Watch →</span>
          </div>
        </div>
      </a>
    `;
  }).join('');
  
  if (clips.length === 0) {
    grid.innerHTML = '<p style="grid-column: 1/-1; text-align: center;">No clips available yet. Check back soon!</p>';
  }
}

function escapeHtml(text) {
  const div = document.createElement('div');
  div.textContent = text;
  return div.innerHTML;
}

// Call on page load
document.addEventListener('DOMContentLoaded', renderLatestClips);
</script>
```

## Multi-Platform Display Options

### Option A: Show Primary Platform (Recommended)

Shows the clip with its primary platform tag:

```javascript
<span class="video-platform">${clip.platform}</span>
```

### Option B: Show All Platforms

Shows all platforms the clip is available on:

```javascript
<span class="video-meta">${clip.platforms.join(' • ')}</span>
```

Example output: `YouTube • Instagram • TikTok`

### Option C: Show Platform Badges

Small badges for each platform:

```javascript
<div class="platform-badges">
  ${clip.platforms.map(p => `<span class="badge">${p}</span>`).join('')}
</div>
```

## Error Handling

Handle cases where the backend is down:

```javascript
async function loadLatestClips() {
  try {
    const response = await fetch(`${BACKEND_URL}/api/feed`, {
      timeout: 5000 // 5 second timeout
    });
    
    if (!response.ok) {
      throw new Error(`HTTP ${response.status}`);
    }
    
    const { success, data } = await response.json();
    
    if (!success) {
      throw new Error('Feed returned error');
    }
    
    return data;
  } catch (error) {
    console.error('Feed load failed:', error);
    
    // Fallback: show static content or message
    return [];
  }
}
```

## Auto-Refresh

Refresh the feed every 5 minutes:

```javascript
// Refresh on page load
renderLatestClips();

// Refresh every 5 minutes
setInterval(renderLatestClips, 5 * 60 * 1000);
```

Or refresh when user clicks a button:

```javascript
<button id="refreshBtn" class="btn btn-secondary">🔄 Refresh</button>

<script>
document.getElementById('refreshBtn').addEventListener('click', () => {
  renderLatestClips();
});
</script>
```

## Performance Tips

1. **Cache on frontend** - Store response in `localStorage` to avoid repeated calls
2. **Lazy load thumbnails** - Use `loading="lazy"` on images
3. **Limit results** - Backend returns top 12; show only 6-9 on homepage
4. **Show loading state** - Placeholder cards while fetching

## Testing

Before going live, test:

1. ✅ Backend is deployed to Zeabur
2. ✅ Environment variables are set
3. ✅ `/api/feed` returns data
4. ✅ Fetch works from your website domain (no CORS issues)
5. ✅ Video cards render correctly
6. ✅ Links work and open videos

## Troubleshooting

**Blank feed / No data shows:**
- Check browser console for errors
- Verify `BACKEND_URL` is correct
- Make sure backend is deployed and environment vars are set
- Check backend logs in Zeabur

**CORS error:**
- Backend has CORS enabled, so this shouldn't happen
- If it does: check browser console, backend should be returning CORS headers

**Links don't work:**
- Verify `clip.url` is correct format
- Test the URL directly in browser

**Slow loading:**
- Backend caches for 30 minutes
- If adding credentials, wait 30 min for next refresh
- Or add `?force=true` to API call (for testing only)
